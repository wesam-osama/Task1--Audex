# Week 1 — Audex Role-aware Shell

## Task

Build a React page shell that displays the active Audex
product/workspace/school and blocks a page for an
unauthorized role.

## Goal

Create a small React demonstration of a role-aware application
shell with route-level authorization.

## Scope

- React page shell
- Active product display
- Active workspace display
- Active school display
- Role-aware route protection
- Unauthorized access state
- Route testing
- Documentation

## Out of Scope

- Backend
- Database
- Real authentication
- Real Audex API
- Full Audex application
- Production deployment

## Assumptions

1. No Audex backend or API is currently available.
2. Product, workspace, and school information will use mock data.
3. User roles and permissions will be defined locally for this demo.
4. Authentication is outside the scope of this task.
5. Authorization will be demonstrated at the route level.

## Acceptance Criteria

- [ ] React shell is implemented.
- [ ] Active Audex product is displayed.
- [ ] Active workspace is displayed.
- [ ] Active school is displayed.
- [ ] User role is represented.
- [ ] Routes are defined.
- [ ] Authorized users can access permitted routes.
- [ ] Unauthorized users are blocked.
- [ ] Unauthorized state is clearly displayed.
- [ ] Route behavior is tested.
- [ ] Screenshots are captured as evidence.
- [ ] README documents the implementation.
